# 504 Network Security

This repository contains an academic project developed for the **504 Network Security** course.

The project consists of building and securing a network environment using **GNS3**. It is divided into several milestones covering the main components of the infrastructure:

* Network routing and firewall configuration
* Site-to-site IPsec VPN
* NGINX reverse proxy and security hardening
* Basic intrusion detection based on web server logs

The repository contains the configurations, implementation notes, network topology, and documentation produced during the course.

## Purpose

This project was created for educational purposes to apply network security concepts in a practical environment.
